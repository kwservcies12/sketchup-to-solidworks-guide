Page 7 Breakdown: Make and change 3D shapes

Direct view showing Push/Pull, Follow Me, and Offset translations into SOLIDWORKS features[cite: 21].

1. Add or remove depth[cite: 21]

SketchUp: Push/Pull (Shortcut: P) — Pull a face out, push it in to remove material[cite: 21].

SOLIDWORKS: Extruded Boss/Base or Cut (Quick access: W) — Sketch a profile, use Boss-Extrude or Cut-Extrude[cite: 21].

Difference: SketchUp edits a face; SOLIDWORKS uses separate sketch-based add and cut tools[cite: 21].

2. Make a shape follow a path[cite: 21]

SketchUp: Follow Me (Shortcut: None) — Choose a path, then sweep a face along it[cite: 21].

SOLIDWORKS: Swept Boss/Base (Quick access: W) — Create a profile sketch and a path, then use Sweep[cite: 21].

Difference: SketchUp sweeps an existing face; SOLIDWORKS requires both a profile sketch and path[cite: 21].

3. Make a parallel outline[cite: 21]

SketchUp: Offset (Shortcut: F) — Select a face or edges, set offset distance[cite: 21].

SOLIDWORKS: Offset Entities (Quick access: W) — In a sketch, select entities and set offset distance[cite: 21].

Difference: SketchUp offsets faces/edges directly; SOLIDWORKS offsets entities inside a sketch[cite: 21].
